# 만들면서 정한 가정

개발기획안 15장 "미정 사항"의 기본값을 따랐고, 문서에 없는 것은 가장 단순한 방법을 골랐다.

| 항목 | 정한 것 |
|---|---|
| 언어 모델 | `claude-sonnet-5-5` (`config.py`의 `LLM_MODEL` 한 줄) |
| 음성 인식 | 넣는다. `OPENAI_API_KEY`가 없으면 녹음 탭을 잠그고 대본 붙여넣기만 쓴다 |
| 진단 기준 | 출제 가능성 점수 20점 이상 전부, 50점 이상 서술형 · 나머지 객관식 |
| 가중치 | v0 그대로. 이 앱으로 기출 비교는 하지 않았다 |
| 빠른 진단 | 상위 5개. 직접 올린 자료이고 대상이 8개보다 많으면 기본 켜짐, 샘플은 꺼짐 |
| 분석 횟수 제한 | 세션당 5번, 서버 전체 하루 150번, 하루 AI 호출 3000번 |
| 학우 질문 기록 | 만들지 않았다 |
| 결과 저장·불러오기(JSON) | 만들지 않았다(시간이 모자랄 때 가장 먼저 줄이는 항목). 결과는 HTML 두 개로 내려받는다 |
| 스크린샷 | 시간 안에 찍지 못하면 README에 자리를 두지 않는다 |
| 구조화 출력 옵션 | 쓰지 않고 "JSON만" 지시 + 첫 `{`부터 마지막 `}`까지 잘라 읽기로 했다 |
| 생각 모드 | 호출 1·2만 `thinking={"type": "adaptive"}`를 넘기고, 3~5는 따로 넘기지 않는다 |
| 샘플 자료 읽기 | `core/sample.py`를 따로 두었다(샘플 PDF·대본과 `tests/fixtures/`의 저장된 분석 결과를 읽는 곳) |
| 인용 검사 | `core/cites.py`를 따로 두었다(순환 import를 피하려고) |
| 메타 페이지 규칙 ① | 첫 줄이 "요약" 등으로 시작해도 바로 뒤에 한글이 이어지면("요약하면 …") 본문으로 본다 |
| 원본 페이지 그림 | 근거 페이지에서 메타 쪽을 뺀 앞 2쪽. 설명이 없으면 그 개념의 등장 페이지에서 고른다 |
| 팀 이름·저장소 | 팀 이름 "빈틈노트", 저장소는 사람이 알려 준 주소 |
