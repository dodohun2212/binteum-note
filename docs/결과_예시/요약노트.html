트리의 기본 용어

보통출제 점수 35헷갈림복습만

출제 가능성 점수 35점

트리는 '계층적인 관계를 표현하는 비선형 자료구조'이며, 예로 폴더 구조, 조직도, 가계도가 있다p.4. 루트(root)는 가장 위의 노드(A)이고, 부모·자식은 간선으로 연결된 위·아래 노드이다(B는 A의 자식, D·E의 부모)p.4. 단말 노드(leaf)는 자식이 없는 노드(D, E, F)이며, 서브트리는 한 노드와 그 자손 전체이다p.4. 용어 요약에서는 깊이는 위에서, 높이는 아래에서 센다고 정리한다p.20. 교수님은 '용어는 어렵지 않으니까 빨리 넘어갑니다.'라고 말했지만녹음, 진단에서 확신 없이 찍어서 맞힌 부분이 있으므로 각 용어의 정의를 직접 말할 수 있는지 확인해야 한다.

핵심
  • 루트 = 가장 위의 노드, 단말 노드(leaf) = 자식이 없는 노드 p.4
  • 부모·자식 = 간선으로 연결된 위·아래 노드 (B는 A의 자식, D·E의 부모)
  • 깊이는 위에서, 높이는 아래에서 센다
자주 하는 실수
  • 깊이(위에서)와 높이(아래에서)를 구분하지 못하고 찍어서 고르기 쉽다
교수님 말
  • “용어는 어렵지 않으니까 빨리 넘어갑니다.” 녹음

노드의 깊이와 높이

자세히출제 점수 66앎복습만

출제 가능성 점수 66점

깊이(depth)는 루트에서 그 노드까지의 경로 길이(간선 수)이며, 루트의 깊이는 0이고 E의 깊이는 2이다p.5. 높이(height)는 그 노드에서 가장 먼 단말 노드까지의 경로 길이이다p.5. 단말 노드의 높이는 0이고 B의 높이는 2이며, 트리의 높이는 루트의 높이와 같아 3이다p.5.

깊이는 위에서 세고, 높이는 아래에서 센다p.5p.20. 같은 노드라도 깊이와 높이는 다를 수 있으며, 노드 E는 깊이 2, 높이 0이다p.5. 연습문제에서는 노드 D의 깊이와 높이, 트리 전체의 높이를 구하게 한다p.19.

교수님은 '깊이는 위에서 세고 높이는 아래에서 센다, 이것만 기억하세요.'라고 강조했다녹음. 또한 '이건 매년 헷갈리는 학생이 많아요.'라며 혼동하지 않도록 경고했다녹음.

핵심
  • 깊이 = 루트에서 그 노드까지의 경로 길이(간선 수), 루트의 깊이 = 0
  • 높이 = 그 노드에서 가장 먼 단말 노드까지의 경로 길이, 단말 노드의 높이 = 0
  • 깊이는 위에서 세고, 높이는 아래에서 센다
  • 트리의 높이 = 루트의 높이 (예제 트리에서 3)
  • 예제 트리의 값: E는 깊이 2·높이 0, B의 높이는 2
자주 하는 실수
  • 깊이와 높이의 방향을 혼동한다. 깊이는 루트에서 위에서부터, 높이는 단말 노드에서 아래에서부터 센다(교수님이 매년 헷갈리는 학생이 많다고 경고함)
  • 같은 노드의 깊이와 높이가 같다고 생각한다. 노드 E는 깊이 2, 높이 0으로 서로 다르다
교수님 말
  • “이건 매년 헷갈리는 학생이 많아요.” 녹음
  • “깊이는 위에서 세고 높이는 아래에서 센다, 이것만 기억하세요.” 녹음

이진 트리의 종류

자세히출제 점수 24모름다음

출제 가능성 점수 24점

이진 트리는 모든 노드가 최대 2개의 자식(왼쪽, 오른쪽)을 가지는 트리다p.6. 종류에는 포화 이진 트리, 완전 이진 트리, 편향 이진 트리가 있다p.6. 포화 이진 트리는 모든 레벨이 꽉 찬 트리이고, 편향 이진 트리는 한쪽으로만 자식이 있는 트리다p.6.

완전 이진 트리는 마지막 레벨을 제외하고 꽉 차 있고, 마지막 레벨은 왼쪽부터 채워진 트리다p.6. 세 종류의 모양은 페이지 그림에서 노드 번호와 함께 확인할 수 있다p.6.

완전 이진 트리는 힙에서 사용된다p.6. 교수님은 '이 중에서 완전 이진 트리, 이게 조금 있다가 힙에서 그대로 쓰입니다.'라고 강조했다녹음. 진단에서 이 개념은 ①을 골랐지만 정답은 ④여서 틀렸으므로 세 종류의 정의를 구분해 확실히 외워야 한다p.6.

핵심
  • 이진 트리 = 모든 노드가 최대 2개의 자식(왼쪽, 오른쪽)을 가지는 트리
  • 포화 이진 트리 = 모든 레벨이 꽉 참
  • 완전 이진 트리 = 마지막 레벨을 제외하고 꽉 차 있고, 마지막 레벨은 왼쪽부터 채워짐 → 힙에서 사용
  • 편향 이진 트리 = 한쪽으로만 자식이 있음
자주 하는 실수
  • 포화 이진 트리(모든 레벨이 꽉 참)와 완전 이진 트리(마지막 레벨은 왼쪽부터 채워짐)의 정의를 혼동한다p.6.
  • 진단 문제에서 ①을 골랐지만 정답은 ④였으므로, 세 종류의 정의를 하나씩 대조해 다시 확인해야 한다p.6.
교수님 말
  • “이 중에서 완전 이진 트리, 이게 조금 있다가 힙에서 그대로 쓰입니다.” 녹음

완전 이진 트리의 배열 표현

자세히출제 점수 32모름다음

출제 가능성 점수 32점

완전 이진 트리는 배열에 빈칸 없이 저장할 수 있으며, 루트를 인덱스 1에 두고 인덱스 0은 비워 둔다p.7.

노드 i의 왼쪽 자식은 2i, 오른쪽 자식은 2i+1, 부모는 i // 2이다p.7. 예를 들어 노드 A~F는 [0]은 비고 [1]=A, [2]=B, [3]=C, [4]=D, [5]=E, [6]=F로 저장된다p.7. 최대 힙 예시는 인덱스 1~7에 [93, 80, 75, 50, 62, 70, 33] 순서로 저장된다p.14.

이 배열 표현은 8.5 힙에서 그대로 사용한다p.7. 힙은 완전 이진 트리이므로 배열로 표현하며, 부모 i의 자식은 2i, 2i+1이다p.14. 교수님은 '이 공식, 조금 있다가 힙 코드에서 그대로 나오니까 외워두시면 편합니다.'라고 강조했다녹음. 진단에서 ③을 골랐으나 정답은 ②였으므로 세 공식과 인덱스 0을 비우는 규칙을 다시 확인해야 한다(진단).

핵심
  • 루트는 인덱스 1에 두고 인덱스 0은 비워 둔다p.7
  • 왼쪽 자식 = 2i, 오른쪽 자식 = 2i+1, 부모 = i // 2 (교수님이 외우라고 강조한 공식)
  • 완전 이진 트리는 배열에 빈칸 없이 저장할 수 있다
  • 8.5 힙에서 이 배열 표현을 그대로 사용한다(부모 i → 자식 2i, 2i+1)
자주 하는 실수
  • 인덱스 0부터 쓰지 않고 루트를 인덱스 1에 두며 인덱스 0은 비워 둔다는 점을 놓쳐 2i, 2i+1, i // 2 공식을 잘못 적용한다(진단에서 ③을 골랐으나 정답은 ②였다)
  • 힙의 배열 [93, 80, 75, 50, 62, 70, 33]을 정렬된 것으로 착각한다. 형제 사이의 순서는 없다p.14
교수님 말
  • “이 공식, 조금 있다가 힙 코드에서 그대로 나오니까 외워두시면 편합니다.” 녹음

이진 트리의 순회

자세히출제 점수 100앎복습만

출제 가능성 점수 100점

순회(traversal)는 트리의 모든 노드를 한 번씩 방문하는 것이다p.8. 루트(V)를 언제 방문하느냐에 따라 세 가지로 나뉘며, 전위 순회(preorder)는 V → L → R, 중위 순회(inorder)는 L → V → R, 후위 순회(postorder)는 L → R → V이다p.8.

세 방법 모두 재귀로 간단히 구현되며, 코드에서는 노드가 None이 아닐 때만 처리하고 n.data를 출력하는 위치만 순회마다 다르다p.10. 수식 트리 예제의 결과는 전위가 + * a b - c d, 중위가 a * b + c - d, 후위가 a b * c d - +이다p.9. 수식 트리를 후위 순회하면 후위 표기식이 되고p.9, 이진 탐색 트리를 중위 순회하면 오름차순으로 값이 나온다p.8.

노드 n개를 각각 한 번씩 방문하므로 시간 복잡도는 O(n)이다p.10. 교수님은 '트리 그림 하나 주고 세 가지 순회 결과 쓰라고 하면 딱 한 문제가 됩니다.'라고 했고, '중위 순회 결과를 쓰는 문제, 이건 시험에 내기 좋죠.'라고도 했다 녹음. 연습문제 1번도 트리의 전위·중위·후위 순회 결과를 각각 쓰는 문제다p.19.

핵심
  • 전위 = V → L → R, 중위 = L → V → R, 후위 = L → R → V
  • 세 순회 모두 재귀로 구현하고, 노드 n개를 한 번씩 방문하므로 O(n)
  • 예제 수식 트리: 전위 + * a b - c d, 중위 a * b + c - d, 후위 a b * c d - +
  • 수식 트리의 후위 순회 = 후위 표기식, 이진 탐색 트리의 중위 순회 = 오름차순
  • 교수님은 이 개념을 중간고사 범위의 핵심으로 꼽았고, 그림을 주고 세 가지 순회 결과를 쓰는 문제를 예고했다
교수님 말
  • “이 중에서 순회하고 힙 삽입·삭제는 중간고사 범위의 핵심이라고 미리 말씀드립니다.” 녹음
  • “중위 순회 결과를 쓰는 문제, 이건 시험에 내기 좋죠.” 녹음
  • “트리 그림 하나 주고 세 가지 순회 결과 쓰라고 하면 딱 한 문제가 됩니다.” 녹음

이진 탐색 트리의 정의와 성질

보통출제 점수 27헷갈림복습만

출제 가능성 점수 27점

이진 탐색 트리(BST)는 탐색을 위해 정렬 규칙을 가진 이진 트리다p.11. 모든 노드에 대해 왼쪽 서브트리 < 노드 < 오른쪽 서브트리이며, 중복된 키는 없다고 가정한다p.11. 이진 탐색 트리를 중위 순회(L → V → R)하면 오름차순으로 값이 나오며, 예시 트리의 중위 순회 결과는 7 18 26 35 50 68 99이다p.8p.11. 탐색과 삽입은 O(h)이다p.20.

핵심
  • BST 규칙 = 모든 노드에서 왼쪽 서브트리 < 노드 < 오른쪽 서브트리, 중복 키 없음
  • 중위 순회(L → V → R) 결과는 오름차순
  • 탐색·삽입 시간 복잡도 O(h)

근거 페이지 p.8p.11p.20

이진 탐색 트리의 탐색과 삽입

자세히출제 점수 65헷갈림다음

출제 가능성 점수 65점

이진 탐색 트리는 왼쪽 < 루트 < 오른쪽 조건을 만족하는 트리이다p.20. 탐색은 루트부터 시작해 키가 작으면 왼쪽, 크면 오른쪽으로 내려간다p.12.

삽입도 같은 방식으로 각 노드와 비교하며 내려가다가 탐색이 실패한 위치(None)에 새 노드를 붙이므로 항상 단말 노드로 삽입된다p.12. 코드에서 insert_bst는 r이 None이면 새 노드 n을 반환하고, n.data < r.data이면 왼쪽, n.data > r.data이면 오른쪽 자식에 재귀로 붙인다p.12. 교수님은 '삽입 순서를 주고 트리를 그리라는 문제도 자주 나와요'라고 강조했다녹음.

탐색과 삽입의 시간 복잡도는 트리의 높이 h에 비례하여 O(h)이다p.12. 균형이 잡히면 O(log n), 편향되면 O(n)이다p.12.

핵심
  • 탐색: 루트부터 시작, 키가 작으면 왼쪽, 크면 오른쪽으로 내려간다
  • 삽입: 비교하며 내려가다 탐색이 실패한 위치(None)에 새 노드를 붙인다 → 항상 단말 노드
  • 삽입 순서가 주어진 문제는 앞에서부터 한 개씩 루트부터 비교하며 넣는다
  • 시간 복잡도 O(h), 균형이면 O(log n), 편향이면 O(n)
자주 하는 실수
  • 삽입 위치만 쓰고, 루트부터 비교하며 내려가는 경로와 탐색이 실패한 빈 자리(None)에 붙어 단말 노드가 된다는 이유를 빠뜨린다
교수님 말
  • “삽입 순서를 주고 트리를 그리라는 문제도 자주 나와요.” 녹음

힙은 완전 이진 트리 + 힙 조건이며 배열로 표현한다p.20. 힙의 삽입 연산은 새 항목을 마지막 위치(배열의 끝)에 넣은 뒤 부모와 비교해 힙 조건을 회복하는 연산이다p.15.

① 새 항목을 마지막 위치(배열의 끝)에 넣으며, 이렇게 하면 완전 이진 트리가 유지된다p.15. ② 부모와 비교해 더 크면 부모와 교환하며 위로 올라가는데, 이를 업힙(sift-up)이라 하고 이 과정으로 힙 조건이 회복된다p.15. 그림의 예에서는 85를 마지막에 추가한 뒤 50, 80과 교환하며 올라가고, 93보다 작으므로 정지한다p.15. 코드의 insert는 heap.append(n)으로 끝에 넣은 뒤 while i != 1 and n > self.heap[i // 2] 동안 부모 값을 아래로 내리고 i = i // 2로 올라간다p.17.

트리 높이만큼만 올라가므로 시간 복잡도는 O(log n)이다p.15. 교수님은 '과정을 그림으로 그리라는 문제가 나올 수 있어요.'라고 말했다녹음.

핵심
  • 삽입 = 마지막 위치(배열의 끝)에 넣고 부모와 비교해 더 크면 교환하며 위로 올라간다 (업힙, sift-up) p.15
  • 시간 복잡도 O(log n): 트리 높이만큼만 올라간다 p.15
  • 힙 삽입 = 마지막에 넣고 업힙, 힙 삭제 = 루트 꺼내고 마지막을 올려 다운힙, 둘 다 O(log n) p.20
  • 진단에서 '모름'으로 표시한 개념이므로 연습문제 4번(최대 힙 [ -, 90, 70, 80, 30, 50, 60 ]에 95 삽입, 단계별 그림과 교환 횟수)을 직접 그려 본다 p.19. 교수님도 '4번 5번은 꼭 풀어보세요.'라고 말했다 녹음
자주 하는 실수
  • 삽입(업힙: 마지막에 넣고 부모와 비교하며 위로)과 삭제(다운힙: 루트를 꺼내고 마지막을 올려 아래로)의 방향을 혼동한다 p.20
  • 교환을 멈추는 시점을 놓친다. 부모보다 크지 않으면 올라가기를 정지한다 p.15

힙의 삭제 연산

힙에서 삭제는 항상 루트(최댓값)를 꺼내는 것이다p.16. 교수님은 '삭제 과정도 시험에 나옵니다.'라고 강조했다녹음.

먼저 루트를 꺼내고, 마지막 노드를 루트 자리로 옮긴다p.16. 그 다음 두 자식 중 더 큰 자식과 비교해 작으면 교환하며 내려가며, 이를 다운힙(sift-down)이라고 한다p.16. 코드에서는 더 큰 자식을 고른 뒤 last >= self.heap[child]이면 멈추므로, 더 큰 자식과 비교한다는 점과 멈추는 이유를 함께 적어야 한다p.17. 예를 들어 93을 삭제한 뒤 33을 루트로 옮기면 80, 62와 교환하며 내려가 [80, 62, 75, 50, 33, 70]이 된다p.16.

삭제의 시간 복잡도는 O(log n)이다p.16. 정리하면 힙 삽입은 마지막에 넣고 업힙, 힙 삭제는 루트를 꺼내고 마지막을 올려 다운힙이며 둘 다 O(log n)이다p.20.

핵심
  • 삭제 = 루트(최댓값)를 꺼내고, 마지막 노드를 루트 자리로 옮긴 뒤 다운힙(sift-down)한다
  • 두 자식 중 더 큰 자식과 비교해 작으면 교환하며 내려가고, 더 큰 자식보다 작지 않으면 멈춘다
  • 시간 복잡도는 O(log n)이다
  • p.16 예시의 결과 배열은 [80, 62, 75, 50, 33, 70]이다
  • 교수님이 '4번 5번은 꼭 풀어보세요.'라고 강조한 연습문제 5번은 삭제 뒤의 배열을 쓰는 문제다p.19
자주 하는 실수

  • 진단에서 배열 결과는 맞혔지만 더 큰 자식과 비교한다는 설명과 멈추는 이유를 쓰지 못해 점수를 잃었으므로 과정과 이유를 함께 서술해야 한다p.16p.17
